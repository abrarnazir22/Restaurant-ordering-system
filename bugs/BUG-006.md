# BUG-006: Driver Location Updates Not Emitted to Socket.IO Clients

- **ID:** BUG-006
- **Severity:** P1 (High)
- **Priority:** High
- **Component:** Delivery Driver API (`src/Routes/delivery.js`)
- **Status:** Verified Fixed

## Description
When delivery drivers sent GPS coordinate updates via `PUT /api/delivery/location`, the backend persisted the location to the database but failed to emit real-time Socket.IO events to customer tracking clients.

## Fix
Injected Socket.IO emission `req.app.get('io').emit('rider:location', { riderId, location })` in the route handler. Verified via API integration runner.
