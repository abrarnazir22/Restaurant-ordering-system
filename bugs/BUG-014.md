# BUG-014: Missing Automated Continuous Integration (CI) Workflow

- **ID:** BUG-014
- **Severity:** P1 (High)
- **Component:** DevOps (`.github/workflows/ci.yml`)
- **Status:** Verified Fixed

## Description
Code changes merged to main without automated test execution, allowing regression defects to reach production staging.

## Fix
Created `.github/workflows/ci.yml` running linting, API integration tests, security audits, and Playwright end-to-end tests across Node 20.
