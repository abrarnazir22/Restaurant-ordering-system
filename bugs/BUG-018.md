# BUG-018: Customer Portal Tab Rendering Race Condition

- **ID:** BUG-018
- **Severity:** P2 (Medium)
- **Component:** Customer Portal JavaScript (`customer.js`)
- **Status:** Verified Fixed

## Description
Switching tabs in the customer portal rendered empty views because UI rendering executed before backend API responses resolved.

## Fix
Refactored `selectTab` and `renderPortal` to properly `await loadCustomerData()` before updating DOM containers. Verified via `tests/e2e/reservations.spec.js`.
