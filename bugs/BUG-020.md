# BUG-020: Global Error Handler Leaks Stack Traces to Client

- **ID:** BUG-020
- **Severity:** P2 (Medium)
- **Component:** Server Error Handling (`server.js`)
- **Status:** Verified Fixed

## Description
Uncaught exceptions returned full internal stack traces and server file paths to the client, exposing sensitive environment details.

## Fix
Sanitized the centralized error handler to return generic safe error messages in production while capturing detailed error stacks in structured server logs.
