# BUG-007: Customer Dashboard Email Container Overflow

- **ID:** BUG-007
- **Severity:** P1 (High)
- **Priority:** High
- **Component:** Customer Dashboard UI (`ember-and-brew/public/customer.css`)
- **Status:** Verified Fixed

## Description
Long customer email addresses (e.g. `alexandra.montgomery-jenkins@enterprise-organization.com`) broke out of their summary card boundaries, causing horizontal scrollbars and visual distortion on mobile screens.

## Fix
Applied `word-break: break-all; overflow-wrap: anywhere;` and responsive font scaling to `.summary-card .value` in `customer.css`. Verified via Playwright visual/layout check.
