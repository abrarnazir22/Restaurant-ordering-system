# BUG-022: Missing Compound Database Indexes on High-Frequency Query Fields

- **ID:** BUG-022
- **Severity:** P2 (Medium)
- **Component:** Database Optimization (`models/Order.js`, `models/Reservation.js`)
- **Status:** Verified Fixed

## Description
Operational queries filtering orders and reservations by `customerId`, `branchId`, `status`, and `createdAt` executed unindexed full collection scans.

## Fix
Added compound indexes:
- `Reservation`: `{ branchId: 1, date: 1, time: 1 }`
- `Order`: `{ customerId: 1, createdAt: -1 }`
- `Complaint`: `{ branchId: 1, status: 1 }`
Verified via `scripts/db-quality-check.js`.
