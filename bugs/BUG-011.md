# BUG-011: Guest Cart Preservation Across Authentication State Changes

- **ID:** BUG-011
- **Severity:** P1 (High)
- **Component:** Storefront Cart (`ember-and-brew/public/index.html`)
- **Status:** Verified Fixed

## Description
When guest customers added items to the cart and subsequently registered or logged in, the cart was overwritten or cleared from browser memory.

## Fix
Preserved `localStorage.getItem('eb_cart')` during session state transitions and synchronized cart across page reloads. Verified via `tests/e2e/checkout.spec.js` (Test `CHK-04`).
