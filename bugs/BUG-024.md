# BUG-024: Missing Automated Synthetic Health Monitoring Probes

- **ID:** BUG-024
- **Severity:** P3 (Low)
- **Component:** Operational Tooling (`scripts/synthetic-monitor.js`)

## Description
No automated mechanism existed to periodically probe customer-facing endpoints and alert on latency anomalies or downtime.

Created `scripts/synthetic-monitor.js` simulating real user transactions across health checks, menu catalogs, and admin portals. Verified via script execution.
