# BUG-021: Missing Interactive OpenAPI / Swagger Documentation

- **ID:** BUG-021
- **Severity:** P2 (Medium)
- **Component:** API Documentation (`openapi.yaml`, `server.js`)
- **Status:** Verified Fixed

## Description
The REST API lacked a formal API specification, making third-party integrations and QA validation difficult.

## Fix
Authored complete OpenAPI 3.0 specification in `openapi.yaml` and mounted interactive Swagger UI at `/api-docs`. Verified by accessing `/api-docs`.
