# BUG-019: Kitchen Status Routes Crash on Malformed MongoDB ObjectIds

- **ID:** BUG-019
- **Severity:** P2 (Medium)
- **Component:** Kitchen API (`src/Routes/kitchen.js`)
- **Status:** Verified Fixed

## Description
Passing a non-24-hex-character string (e.g. `/api/kitchen/invalid-id/accept`) caused unhandled CastErrors resulting in HTTP 500 crashes.

## Fix
Added `isValidObjectId(id)` validation returning HTTP 400 Bad Request on malformed identifiers. Verified via `tests/api/api-runner.js` (Category 5: Kitchen API).
