# BUG-009: Missing Rate Limiting on API and Auth Endpoints

- **ID:** BUG-009
- **Severity:** P1 (High)
- **Priority:** High
- **Component:** API Gateway (`server.js`)
- **Status:** Verified Fixed

## Description
Endpoints lacked rate limiting, allowing unbounded automated brute force attacks against customer and staff login routes.

## Fix
Implemented `express-rate-limit` with global API limiter (100 req/15 min) and strict auth limiter (10 req/15 min). Verified via `tests/security/security.spec.js` (Test `SEC-04`).
