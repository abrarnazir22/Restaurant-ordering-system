# BUG-023: Modals and Dialogs Lack Accessible ARIA Roles and Focus Traps

- **ID:** BUG-023
- **Severity:** P2 (Medium)
- **Component:** Accessibility (`ember-and-brew/public/index.html`)
- **Status:** Verified Fixed

## Description
Modal dialogs (dish details, cart drawer, complaint form) lacked `role="dialog"`, `aria-modal="true"`, and accessible labels, hindering screen reader users.

## Fix
Added semantic ARIA landmark roles, accessible name labels, and keyboard escape listeners. Verified via `tests/e2e/accessibility.spec.js`.
