# BUG-015: Inconsistent Typography Across Customer Portal and Storefront

- **ID:** BUG-015
- **Severity:** P2 (Medium)
- **Component:** Frontend Styling (`customer.css`, `index.html`)
- **Status:** Verified Fixed

## Description
Customer portal used disparate fonts compared to the storefront branding, producing jarring visual inconsistency.

## Fix
Unified typography stack across all portals to Google Font **DM Sans** with consistent weights and letter-spacing. Verified via `tests/e2e/visual.spec.js`.
