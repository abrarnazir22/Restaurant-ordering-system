# BUG-017: Customer Input Fields Blanked Out Asynchronously While Typing

- **ID:** BUG-017
- **Severity:** P2 (Medium)
- **Component:** Customer Portal JavaScript (`customer.js`)
- **Status:** Verified Fixed

## Description
Typing in customer input fields triggered an asynchronous delayed `setTimeout` that reset input values to empty strings mid-entry.

## Fix
Removed unnecessary delayed timeout resets and preserved user-entered input values in state. Verified via `tests/e2e/auth.spec.js`.
