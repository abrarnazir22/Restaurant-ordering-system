# BUG-004: Guest Reservations Orphaned on User Registration

- **ID:** BUG-004
- **Severity:** P0 (Critical / Blocker)
- **Priority:** High
- **Component:** Customer Auth & Reservations (`src/Routes/customerAuth.js`)
- **Reported By:** Quality Engineering Lead
- **Status:** Verified Fixed

## 1. Description
When a guest creates a table reservation before registering an account, the reservation document retained `customerId: null`. When the guest subsequently registered using the same phone number, their previous reservation was invisible on their customer portal.

## 2. Fix Applied
Added helper `claimGuestReservations(customer._id, customer.phone)` in `src/Routes/customerAuth.js` which links any unassigned reservations matching the customer's phone number during registration and login.

## 3. Verification
Verified via `tests/api/api-runner.js` (Category 3: Reservation Flow).
