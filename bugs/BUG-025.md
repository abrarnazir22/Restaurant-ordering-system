# BUG-025: Order State Machine Allows Illegal Lifecycle Transitions

- **ID:** BUG-025
- **Severity:** P3 (Low)
- **Component:** Order Management (`src/Routes/orders.js`)
- **Status:** Verified Fixed

## Description
Orders could transition arbitrarily between disjoint terminal states (e.g. from `cancelled` directly to `delivered` or `preparing`).

## Fix
Enforced order lifecycle state validation ensuring orders advance monotonically along valid progression paths (`received` -> `preparing` -> `ready` -> `completed` / `out-for-delivery` -> `delivered`). Verified via `tests/api/api-runner.js`.
