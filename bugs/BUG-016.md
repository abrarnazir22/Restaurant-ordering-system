# BUG-016: Menu Navigation Link Inaccessible from Customer Header

- **ID:** BUG-016
- **Severity:** P2 (Medium)
- **Component:** Customer Navigation (`customer.html`, `customer.js`)
- **Status:** Verified Fixed

## Description
When authenticated in the customer portal, the top navigation header had no direct link to return to the public menu storefront.

## Fix
Added prominent "Browse Menu" button (`#nav-menu-link`) to top navigation header preserving active branch parameter. Verified via `tests/e2e/storefront.spec.js` (Test `MNU-09`).
